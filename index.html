담당 업무

  • 길드 및 길드원 관리 기능 설계·개발
  • 서브·기사 캐릭터 관리 기능 구현

트러블슈팅

Spring Boot Jar를 Launch4j로 .exe 변환 시 서버가 구동되지 않는 문제가 발생했습니다. GUI 빌드 대신 ./gradlew clean bootJar로 직접 빌드한 공식 jar를 Launch4j에 적용해 해결했습니다.

느낀점

기획부터 실행 파일 생성까지 개발 프로세스를 단독으로 경험하며, MVC 패턴 적용과 빌드·배포 과정에 대한 이해를 높일 수 있었습니다.

AI 클린코드 학습 플랫폼

2025.03 – 2025.06

백엔드·프론트엔드·팀장

Spring Boot React MySQL ChromaDB Llama

프로젝트 개요

AI를 활용해 개발자의 알고리즘 사고력과 코드 품질을 함께 향상시키는 교육 플랫폼. 자연어로 작성한 문제 해결 과정을 AI가 분석하는 "프롬프트 기반 알고리즘 검사"와, 코드를 분석해 개선점을 제시하는 "AI 클린코드 리뷰" 두 가지 핵심 기능으로 구성됩니다.

담당 업무

  • 문제 생성 및 목록/관리 기능 구현
  • 채점 현황 및 코드 채점 기능 구현
  • 업적·순위·프로필 기능 구현
  • JWT 기반 인증 및 세션 유지 처리
  • 전체 UI 디자인 담당
  • 팀장으로서 발표와 형상 관리 주도

트러블슈팅

AI가 존재하지 않는 클린코드 규칙을 생성하는 할루시네이션 문제가 발생했습니다. ChromaDB 기반 RAG(Retrieval-Augmented Generation)를 도입해 154개의 검증된 규칙을 벡터화하고, 제목·설명·카테고리에 가중치를 적용한 벡터 검색으로 관련 규칙을 선별함으로써 해결했습니다.

느낀점

담당 영역은 백엔드·프론트엔드였지만, 팀 전체의 기술 스택을 이해하려 노력한 덕분에 AI 팀원의 문제까지 파악하고 해결 방향을 제시할 수 있었습니다. 팀장으로서 협업 관리의 중요성을 체득한 프로젝트였습니다.

담당 업무

  • 로그인/회원가입, 메인·순위·업적·코드 제출 페이지 구현
  • 프론트엔드-백엔드 API 연동 구현
  • 칸반 보드를 활용한 프로젝트 일정 관리
  • 코드 리뷰와 GitHub 병합 관리 총괄 (팀장)

트러블슈팅

느낀점

임시방편이 아닌 근본적인 해결책을 고민하는 자세의 중요성을 깨달았습니다. IoT6기 프로젝트 경연대회에서 장려상을 수상했습니다.
